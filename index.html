Medidas de variabilidad, forma y diagrama de cajas

Qué tan dispersos están: la otra mitad de la historia

Dos conjuntos de datos pueden tener la misma media y ser completamente distintos. En este laboratorio calculas rango, rango intercuartílico, varianza, desviación estándar y coeficiente de variación; comparas la variabilidad de una variable continua dentro de cada categoría de una nominal; aplicas las propiedades de la varianza; mides asimetría y curtosis, y construyes el diagrama de cajas. Un contexto distinto en cada intento. Tienes 20 minutos.

Lo que vas a usar
Rango y RIR = Xmáx − Xmín. El rango intercuartílico RI = Q₃ − Q₁ recoge el 50 % central.
Varianza y desviacións² con la fórmula abreviada; s = √s², en las mismas unidades que los datos.
Coeficiente de variaciónCV = (s / x̄) × 100. Sirve para comparar grupos con distinta media o distinta unidad.
FormaAsimetría Ak = 3(x̄ − Me)/s: hacia qué lado se estira la distribución.
ConcentraciónCurtosis Ku a partir de los percentiles: qué tan apuntada es frente a la curva normal.
Diagrama de cajasQ₁, Me y Q₃ forman la caja; fuera de [Q₁ − 1.5 RI ; Q₃ + 1.5 RI] están los atípicos.
Varianza muestral (fórmula abreviada): s² = ( Σ xᵢ² − n x̄² ) / ( n − 1 ) Desviación estándar: s = √s² Coeficiente de variación: CV = (s / x̄) × 100 Propiedades de la varianza s² ≥ 0 siempre y de una constante: s²(c) = 0 yᵢ = xᵢ ± b → s²ᵧ = s²ₓ , sᵧ = sₓ yᵢ = c · xᵢ → s²ᵧ = c² s²ₓ , sᵧ = |c| sₓ yᵢ = c · xᵢ ± b → s²ᵧ = c² s²ₓ , sᵧ = |c| sₓ Forma Ak = 3 (x̄ − Me) / s Concentración Ku = (Q₃ − Q₁) / [ 2 (P₉₀ − P₁₀) ] = (P₇₅ − P₂₅) / [ 2 (P₉₀ − P₁₀) ] La posición de cada percentil se ubica con j = k(n + 1)/100 y, si j no es entero, Pk = Li + dec × (Ld − Li), igual que en la Sesión 2. Recuerda: Ak < 0 asimetría negativa, Ak = 0 simétrica, Ak > 0 asimetría positiva. Ku = 0.263 mesocúrtica, menor platicúrtica, mayor leptocúrtica.
